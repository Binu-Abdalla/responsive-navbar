description: Review my code as a learning coach
---

Review my current code.

Do NOT rewrite it.

Give me a concise review divided into:

1. BUGS
Actual things that are wrong or broken.

2. LEARNING
Important concepts I should understand from this code.

3. IMPROVEMENTS
Useful improvements that are not required for correctness.

4. NEXT
One thing I should work on next.

Do not overwhelm me with minor style preferences.

Prioritize things that will make me a better developer.

If something is already good, leave it alone.
